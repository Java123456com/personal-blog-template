# Linked nodes

Reference: `https://yihanglizi.cn/friends/`.

## Content

- Module `#02 已连节点 · Linked Nodes` contains seven public friend cards from the reference.
- Cards show avatar, node id, address, description, ping, and warp action.
- The page ends after module 02. The reference request or application module is intentionally omitted.

## Interaction

- List view is the default.
- “星图” hides the grid and shows the seven nodes around the local core.
- Friend nodes can be dragged within the map; connection lines redraw as they move.
- Reset clears manual positions and restores the orbit layout.
- Clicking a card or an undragged node opens the corresponding public site in a new tab.
- Before navigation, a full screen warp HUD identifies the target, draws accelerating star trails, streams connection logs, and fills a progress meter. Escape cancels the jump.
