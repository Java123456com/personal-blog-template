# 工具目录复刻规格

## 目标

复刻原站 `/tools/` 的国产 AI 编程工具目录，同时沿用本项目已有的全站导航、星空极光与赛博编程主题。

## 内容与顺序

- 页面标题、说明、统计栏和 17 个工具卡片来自原站公开页面。
- 按用户要求逆序展示，从 `AtomCode` 开始，以 `Trae CN` 结束。
- 每张卡片展示本地图标、工具名、厂商、简介、标签和“查看详情”入口。
- 原站右下角跳转 Bilibili 的气球及链接不渲染。

## 布局

- 主内容最大宽度为 960px，与原站一致。
- 桌面端为三列自适应网格；窄屏自动降为两列或一列。
- 卡片使用半透明主题色背景、边框、圆角、悬浮抬升和品牌色光晕。

## 交互

- 点击卡片或聚焦后按 Enter/Space 进入详情。
- 图片加载失败时保留浏览器替代文本，不阻断详情浏览。
- 所有图标和界面预览保存到本地站点命名空间，页面不依赖原站资源。
