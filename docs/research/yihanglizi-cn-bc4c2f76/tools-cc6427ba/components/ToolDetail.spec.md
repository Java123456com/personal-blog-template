# 工具详情复刻规格

## 信息结构

- 返回工具列表。
- 品牌图标、标签、工具名、厂商和简介。
- 三项摘要数据和工具界面预览。
- 官方地址、官网按钮与支持平台。
- GUI、CLI、IDE/Web 等运行形态及支持状态。
- 四项核心能力。
- 按逆序目录切换的“上一个 / 下一个”。

## 行为

- 详情在 `/tools/` 页面内切换，与原站行为一致。
- 返回、翻页后平滑滚动到页面顶部。
- Escape 可从详情返回目录。
- 官网链接在新标签页打开，并添加 `noopener noreferrer`。

## 响应式

- 640px 以下详情头部纵向排列，下载区改为纵向。
- 运行形态与核心能力网格随容器宽度折行。
- 不出现横向滚动或被固定导航遮挡的内容。
