# Game2048 Specification

## Overview
- **Target file:** `src/components/sites/yihanglizi-cn-bc4c2f76/root-8a5edab2/game.ts`
- **Screenshot:** `docs/design-references/yihanglizi-cn-bc4c2f76/root-8a5edab2/desktop.png` (capture scheduled after local browser setup)
- **Interaction model:** keyboard arrows/WASD and touch swipe; time driven knight animation.

## DOM Structure
Existing source markup under `.game-wrap > .cyber2048` is retained. `.c2048-head` contains title and SCORE/BEST. `.c2048-stage` contains `.c2048-board > .c2048-bg` with 16 `.c2048-bg-cell` children, absolutely positioned `.c2048-tile` nodes, scan overlay, and sibling `.knight` sprite. `.c2048-foot` gives controls and KNIGHT meter. Enhance this existing DOM instead of replacing it.

- `.c2048-tile`: 87.2×87.2px desktop, absolute location via `left: col*25%; top: row*25%` with `data-row` and `data-col`. Inner classes `t2`, `t4`, etc. Original scoped CSS is copied locally; keep `data-v-5c7e5b93` on new nodes.
- `.c2048-board` is 239px square at mobile width 390px. Original CSS owns responsive dimensions.

## States & Behaviors
- Initialize two tiles of value 2/4 at random empty cells. The reference loaded with a 4 at (row 1,col 2) and a 2 at (row 3,col 2), but location varies by reload.
- ArrowLeft/Right/Up/Down and A/D/W/S slide rows/columns toward the direction; equal neighbors merge once per move, increment score, and spawn a 2 (occasionally 4) in an empty cell if board changed.
- Persist BEST in localStorage. Detect win at 2048 and no-move game over, showing feedback in the board. Any restart controls in feedback reset the board.
- Touch start/end on board decides direction for swipes. Avoid hijacking keyboard input when a modal or editable field has focus.
- Update `.c2048-stat-v.gold` and the following BEST value, tile DOM, classes, and `KNIGHT ×1` counter. Keep visual changes driven by original CSS transitions and `.is-new` / `.is-merged` classes.
- Knight sprite asset: `/sites/yihanglizi-cn-bc4c2f76/root-8a5edab2/knight/Idle.png`, 600×90 sprite in `.knight-sprite`.
