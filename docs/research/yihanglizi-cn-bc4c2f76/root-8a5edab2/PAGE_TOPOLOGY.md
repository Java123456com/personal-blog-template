# Page topology

1. Fixed VitePress navigation, search, a social dropdown, background selector, sound settings, and mobile menu.
2. Main `.wasteland` terminal background with matrix rain canvas, scanlines, vignette, and floating pixel cat.
3. `.hud-bar` with OS label, signal bars, and live time.
4. `.hero`: desktop two-column terminal and SYS_STATUS telemetry; one column below about 900 px.
5. `.quests`: six link cards, two columns on desktop, one on tablet and phone.
6. `.game-section` / `.game-wrap`: playable keyboard and touch 2048 board with animated knight sprite.
7. `.signal-widget`: animated technology ticker.
8. `.vim-bar`: editor status strip.
9. Footer with copyright and filing link.

The nav is fixed. The main page scrolls natively. The ENTER action smoothly scrolls to quests; the DECRYPT action opens an overlay. The game is keyboard and swipe driven. The header is unchanged on scroll.
