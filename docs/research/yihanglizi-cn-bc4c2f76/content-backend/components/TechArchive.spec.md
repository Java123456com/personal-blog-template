# TechArchive 规格

参考：`https://yihanglizi.cn/blog/`。目标组件：`src/components/content/TechArchive.tsx`，样式独立放在 `TechArchive.css`。

## 结构及样式

- 沿用当前全站导航与背景，顶部横幅使用现有博客横幅素材。参考横幅桌面高度约 634px，标题为 83.2px 的楷体风格；用户现有主题色与个人博客文案优先。
- 内容区参考 `.bl`：全宽，顶部 35px、底部 64px；中央卡片列参考 `.bl-inner` 宽 920px、左右内边距 48px。用户要求全站宽度统一，外层可采用 `--clone-page-width`，卡片列保持舒适阅读宽度。
- 文章卡参考 `.bl-card`：半透明深色背景、1px 边框、16px 圆角、上下约 24px、左右 27–32px 内边距。卡片依次展示编号/分类、标题、摘要、标签、日期、阅读链接。
- 横幅下提供文章索引或文章数量。右侧固定易发现的「＋ 记录」入口，链接 `/write/?type=article`。
- 空状态展示「还没有文章」，不放参考作者内容。

## 行为及响应式

- 交互模型：卡片点击进入 `/moments/tech/[slug]/`；文章锚点可滚动定位；记录入口进入编辑器。
- 文章列表来自 `ContentEntry[]`，只展示已发布的文章。桌面中心列，窄屏单列，卡片宽度随容器收缩，不横向溢出。
